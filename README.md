# Q.A.M.L.

Quality Assurance Minus the Labour. A fast Browser Agent that can test a web application and publish success critiera.

To install dependencies:

```bash
bun install
```

To run:

```bash
bun run index.ts
```

This project was created using `bun init` in bun v1.4.2. [Bun](https://bun.com) is a fast all-in-one JavaScript runtime.
